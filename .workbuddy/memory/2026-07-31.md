# 2026-07-31

## 主体性休闲调度系统重建（提交 72f3757）

**问题根因**：
- 潜意识过度依赖主动休息（日均40次，7月30日单日139次，占工具调用29%）
- 6条冲动规则全部依赖已删除的neuromod子系统（2026-07-24提交8a17a411删除），ImpulseSection恒为空输出
- 休息工具调用被错误计为有效行动，导致idle计数失效
- prompt中7处重复鼓励休息文本，强化"没有想做的事→休息"短路

**实施方案**：
1. **重写drives/rules.py**：移除5条失效规则，新增6条基于现存可审计状态的规则（thought_deepen/curiosity_engage/learning_reflect/river_consolidate/intent_review/todo_attend），修正thought_pursue逻辑互斥
2. **新增LeisureOpportunitySection**：替换失效的ImpulseSection，以邀请而非任务形式呈现机会快照，保持主体性（有候选时仍允许选择休息或安静结束）
3. **扩展恢复性休息状态机**：新增checkpoint_minutes/consecutive_rest_count/last_leisure_seen_at字段；休息期间每30分钟检查点重评估；外部消息解锁时重置连续计数
4. **清理休息偏置**：移除tools/rest_tools.py中"暂时没有真正想推进的事"偏置；清理core.py中7处重复鼓励休息文本；区分安静结束与主动休眠
5. **修正idle计数**：core.py中使休息工具调用不算有效行动

**设计原则**（主体性不变量）：
- 不以产出率裁决选择
- 不因系统认为某事"更有价值"就强迫承接
- 所有变化可见/可追溯/可撤销
- 安静结束一轮不需要调用任何工具
- 有候选时仍允许明确选择休息
- 共现/重复/承接频率不能影响事实真实性
