# 默认主体 Skill：TODO 再提醒

文档类型：工程提供、可由爱莉重写、替换或删除的可选流程建议。这不是爱莉已经接受的任务安排。

## 使用前提

本建议本身不安装能力、不登记机会，也不执行任何 TODO。安装能力、显式登记 `at` / `interval` 时间机会和真正执行是三个独立决定；当前不会扫描旧 TODO due_at 并自动创建提醒机会。

## 可选流程

1. 看到提醒时，先用 `nucleus_todo` 的 list 或 get 核对真实条目、状态与 due_at。
2. 自己决定现在处理、保持原样、修改表述、标记完成或取消；到期不要求行动。
3. 需要变更时，用 write 提交带稳定 ID 的明确状态；条目描述的外部工作仍需另行选择和授权。
4. 写入后核对返回的当前板，不把工具失败当成状态已改变。
5. 可以改写提醒习惯、暂停提醒，或移除整个能力而保留 TODO 板。

## 不变边界

- 沉默、忽略、延后或保持原样都是完整结果。
- 本 Skill 不自动执行 TODO，也不替爱莉判断哪一项更值得做。
- 本 Skill 不增加任何外部动作或数据权限。
- 未确认写入时不更新认知中的任务状态，不制造完成记录。
