# 默认主体 Skill：认识探索

文档类型：工程提供、可由爱莉重写、替换或删除的可选流程建议。这不是爱莉已经产生的好奇或结论。

## 使用前提

本建议本身不安装能力、不登记机会，也不执行任何操作。安装能力、显式登记 `at` / `interval` 时间机会和真正执行是三个独立决定；没有另行安排或手动调用时，不会因为采用本建议而自动出现机会。

## 可选流程

1. 先核对机会的来源和开放问题；把它视为外部候选，而不是自己的既定兴趣。
2. 自己决定忽略、保留、改写问题，或现在探索。
3. 若选择探索，可从已声明的记忆、事件或网络读取工具中挑选必要的一个；只读取当前判断所需范围。
4. 区分观察、他者说法、主体见证和仍有冲突的解释；检索顺序不构成证据等级。
5. 如果后来确实想持续关注，可另用主体拥有的 AttentionThread 能力写下自己的表述；本流程不自动代写。

## 不变边界

- 沉默、无兴趣、暂时未知或稍后再看都是完整结果。
- 本 Skill 不自动执行搜索，不替爱莉形成问题、信念或结论。
- 本 Skill 不增加本地数据或网络访问权限，也不授权对外发送。
- 来源不足或工具失败时保持未知，不把空结果解释为不存在。
