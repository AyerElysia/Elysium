# 记忆连续性复盘

文档类型：工程能力手册；不是主体 Skill，也不是主体表达。

## 安装、安排与执行

安装只让本能力的说明与操作白名单可被发现；它不会登记时间策略、产生动态机会或调用任何操作。安装不等于安排，安排不等于执行。

主体可以通过统一机会管理面为本能力显式登记 `at` 或 `interval` 时间机会，并查询每次机会的来源；这些管理动作不扩大 manifest 中的领域权限。除 `initiative_reencounter` 已有的 Initiative 来源桥外，当前内置包不会根据旧 Learning、Memory、TODO、文件计数或其他领域到期事实自动生产机会。本能力没有旧 Memory 计数或复盘到期的自动来源桥。

## 客观能力

本能力提供一条可恢复的 MEMORY.md 复盘会话：固定统一主体 revision，分页读取精确来源，机械组装候选，分页核对候选，并记录接受请求、拒绝、保持开放、不变或延后。长内容使用有界页面与精确续读位置，权威原文不因传输预算被裁剪。

`nucleus_memory_continuity_review` 只执行主体明确提交的字节范围、文本编辑和决定。基础设施不会自行挑选值得保留的记忆，也不会从访问次数或检索顺序推导长期意义。

## 可观察副作用

- 打开与读取是受控只读操作；准备候选会追加候选及来源证据。
- 接受请求通过 Subject Authority 的 actor、revision、内容哈希和投递回执校验后，才可能产生新的 MEMORY.md 版本。
- 不变和延后会留下可重放的主体决定证据，但不会改写 MEMORY.md。

## 安全边界

- 未完整核对候选、actor 非 active、主体 revision 冲突或回执不精确时，接受必须关闭失败。
- 辅助来源只通过受控 logical path、不可变版本和精确字节范围引用。
- 工程层不得创作、润色或删改第一人称记忆。
- 本能力不扩大文件或 Subject Authority 权限；失败保留会话与证据。

## 移除后的行为

移除后不再产生新的记忆复盘机会，也不再从本能力开启新会话。已经存在的主体文档、不可变版本、候选和决定历史不删除；其他获授权的记忆读取能力不因此改变。
