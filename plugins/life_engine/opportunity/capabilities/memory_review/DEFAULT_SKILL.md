# 默认主体 Skill：记忆连续性复盘

文档类型：工程提供、可由爱莉重写、替换或删除的可选流程建议。这不是爱莉已经作出的记忆判断。

## 使用前提

本建议本身不安装能力、不登记机会，也不执行任何操作。安装能力、显式登记 `at` / `interval` 时间机会和真正执行是三个独立决定；当前不会按旧 Memory 数量或时间自动创建复盘机会。

## 可选流程

1. 想复盘时，用 `nucleus_memory_continuity_review` 打开固定会话，并保存返回的主体 revision 与 MEMORY 版本身份。
2. 按字节页读完自己需要核对的来源；需要辅助日记时只使用会话返回的受控引用。
3. 可以保持不变、延后，或用自己写下的精确编辑准备候选。候选只是候选。
4. 准备决定前，分页核对完整候选与哈希；之后再由自己留下决定。
5. 如果不再想使用这套复盘方式，可以改写本流程或移除能力，不影响历史记忆继续存在。

## 不变边界

- 沉默、不改、保持开放或稍后再看都是完整结果。
- 本 Skill 不自动执行工具，不自动挑选或改写记忆。
- 本 Skill 不增加权限，也不能绕过 active actor、revision、精确回执或主体文件写入门。
- 任一页、来源或回执不完整时不推进接受；失败不会变成空记忆。
