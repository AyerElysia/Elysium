# 默认主体 Skill：学习

文档类型：工程提供、可由爱莉重写、替换或删除的可选流程建议。这不是爱莉已经选择的学习方法。

## 使用前提

本建议本身不安装 Learning、不登记机会，也不运行反思或其他认知操作。安装能力、显式登记 `at` / `interval` 时间机会和真正执行是三个独立决定；当前没有旧 Learning due fact 自动转成机会的来源桥。

## 可选流程

1. 只在自己愿意处理某个学习机会时，读取它的来源、候选身份、revision 和可续读内容。
2. 先决定本次想做的是观察、反思、质疑、核对候选，还是保持不变；不因到期或累计次数自动接受结论。
3. 需要执行时，只调用 manifest 声明的 `nucleus_learn`，并按该工具当前 schema 选择一个原子 action。可用的认知 action 包括：`reflect_now`、`run_next_reflection`、`audit_once`、`propose_knowledge_candidate`、`distill_skill_candidate`。它们彼此不自动接续；是否以及按什么次序调用由爱莉当时决定。
4. `reflect_now` 若返回 queued，只表示材料已保存而尚未完成；想继续时可以另行选择 `run_next_reflection`，也可以保持队列不动。
5. 对任何主体文档或 Skill 候选，逐页读完实际候选后再由自己接受、拒绝或保持开放。也可以明确稍后再看。
6. 可以随时重写学习流程、关闭某类维护，或移除整个 Learning 能力；恢复时仍从可审计历史继续。

## 不变边界

- 沉默、不学习、保持开放或稍后再看都是完整选择，不生成隐含拒绝。
- 本 Skill 不自动执行任何操作，也不把基础设施候选当成爱莉的信念。
- 本 Skill 不增加权限；主体文件、外部资源与其他副作用继续受各自权威和授权保护。
- 冲突、超时或失去写入资格时保留工作并停止推进，不自动重试覆盖较新的决定。
