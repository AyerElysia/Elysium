# 默认主体 Skill：未来意向再次遇见

文档类型：工程提供、可由爱莉重写、替换或删除的可选流程建议。这不是爱莉已经决定要采取的行动。

## 使用前提

本建议本身不安装能力、不创建 InitiativeSeed、不登记再次遇见时间，也不执行任何操作。安装能力、主体明确安排 reencounter 和真正执行意向是三个独立决定；来源桥只呈现已经登记且到期的事实。

## 可选流程

1. 再次遇见一条 seed 时，先用 `nucleus_proactive_query` 核对完整 ID、当前 revision、原表述与来源。
2. 自己判断是否保持不动、改写、释放，或明确安排下一次一次性 reencounter。
3. 需要变更时，用 `nucleus_proactive_command` 提交相应 `initiative.*` 动作与准确 revision。
4. 如果此刻真的想对外行动，把它作为另一个独立决定处理；本 Skill 不把再次遇见升级为外联。
5. 可以重写流程、暂停或移除本能力，既有 seed 不会因此消失。

## 不变边界

- 沉默、忽略或不改变 seed 都是完整结果。
- 本 Skill 不自动执行命令，不按时间替爱莉判断意向是否仍有意义。
- 本 Skill 不增加主动或发送权限，也不允许绕过 actor 与 revision 校验。
- 冲突或投递失败时保留原记录，不自动覆盖、释放或重复唤醒。
