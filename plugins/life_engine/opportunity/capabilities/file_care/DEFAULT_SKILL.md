# 默认主体 Skill：文件照料

文档类型：工程提供、可由爱莉重写、替换或删除的可选流程建议。这不是爱莉已经选择的整理方案。

## 使用前提

本建议本身不安装能力、不登记机会，也不执行任何操作。安装能力、显式登记 `at` / `interval` 时间机会和真正执行是三个独立决定；没有另行安排或手动调用时，不会因为采用本建议而自动出现机会。

## 可选流程

1. 先读取机会给出的目录、数量与来源引用，必要时只读列出或抽查文件。
2. 自己判断是否真的想改变当前结构；继续保持现状也是完整选择。
3. 如果要处理，先选择最小、可核对的改动，并通过 manifest 中声明的文件工具执行。
4. 写入后检查真实结果；路径或内容不确定时停止，不批量猜测。
5. 可以重写照料方式、改变检查节奏，或移除此能力。

## 不变边界

- 沉默、忽略或不整理都是完整结果。
- 本 Skill 不自动执行文件操作，也不替爱莉决定哪些内容该保留。
- 本 Skill 不增加路径或写入权限，不能绕过主体文件与历史身份保护。
- 失败或部分完成必须显式保留，不把未执行的改动视为成功。
