# 默认主体 Skill：内心回声交还

文档类型：工程提供、可由爱莉重写、替换或删除的可选流程建议。这不是爱莉已经形成的回声内容。

## 使用前提

本建议本身不安装能力、不登记机会，也不执行任何操作。安装能力、显式登记 `at` / `interval` 时间机会和真正执行是三个独立决定；没有另行安排或手动调用时，不会因为采用本建议而自动出现机会。

## 可选流程

1. 在潜意识中看到待交还机会时，用 `nucleus_proactive_query` 核对 inner_dialogue receipt、原始窗口和当前状态。
2. 自己判断是否现在有话想交还；可以保持安静，让 receipt 继续开放。
3. 如果确实形成了回声，只用自己此刻的语言写 statement，再由 `nucleus_proactive_command(action=inner.return)` 提交。
4. 交还后让原表达窗口重新判断，不预设它必须说话或照抄回声。
5. 可以重写流程、暂停或移除本能力，历史对话不因此改变。

## 不变边界

- 沉默、不交还或稍后再看都是完整结果。
- 本 Skill 不自动执行 return，不提供可复制的回声正文，也不强迫表达。
- 本 Skill 不增加权限；只能使用原 receipt、原 stream 与 heartbeat actor 的正式门。
- 事件已提交而唤醒失败时保留待投递状态，不重复创作或伪装送达。
