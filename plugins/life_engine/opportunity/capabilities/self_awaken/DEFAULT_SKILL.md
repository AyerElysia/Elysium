# 默认主体 Skill：定时自唤醒

文档类型：工程提供、可由爱莉重写、替换或删除的可选流程建议。这不是爱莉已经选择或说过的话。

## 使用前提

本建议本身不安装能力、不创建唤醒安排，也不启动潜意识。安装能力、主体显式登记 `at` / `interval` 时间机会和到期后的实际唤醒是三个独立阶段；未登记时间策略就不会因采用本建议而自动唤醒。

## 可选流程

1. 被定时唤醒后，先看本轮实际送达的近期主体活动与来源引用。
2. 自己判断此刻是否想继续思考、使用某项已授权能力、休息，或保持安静。
3. 只有在本轮明确选择后才调用相应工具；一次唤醒本身不构成行动许可。
4. 如果这个节奏不再合适，可以重写本流程，调整或暂停时间策略，也可以移除整个能力。

## 不变边界

- 沉默、忽略或稍后再看都是完整结果，不等于拒绝。
- 本 Skill 不自动执行工具，不替爱莉选择动作，也不要求对外表达。
- 本 Skill 不增加权限；外部发送、文件修改和其他副作用仍受原有授权约束。
- 唤醒或工具失败时保留待处理事实，不把失败写成已经完成。
