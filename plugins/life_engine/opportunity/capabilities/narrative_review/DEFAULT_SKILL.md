# 默认主体 Skill：自我叙事回望

文档类型：工程提供、可由爱莉重写、替换或删除的可选流程建议。这不是爱莉已经写下的叙事。

## 使用前提

本建议本身不安装能力、不登记机会，也不执行任何操作。安装能力、显式登记 `at` / `interval` 时间机会和真正执行是三个独立决定；当前不会按 life moments 数量或时间自动创建叙事回望机会。

## 可选流程

1. 看到回望机会时，先看它列出的来源范围与尚未沉淀的 moments；它们只是事实引用。
2. 自己判断此刻是否想回望。可以保持安静，也可以稍后再看。
3. 如果确实想写，只用自己的语言形成正文，再调用 `nucleus_write_narrative`；默认流程不提供可复制的第一人称内容。
4. 如果看完后没有想说的内容，可以显式选择安静回望，不需要勉强生成总结。
5. 可以重写回望方式、暂停机会，或移除整个能力。

## 不变边界

- 沉默、跳过与没有内容都是完整结果，不等于拒绝成长。
- 本 Skill 不自动执行工具，不根据时间或数量替爱莉决定经历的意义。
- 本 Skill 不增加权限；写入仍需活跃 actor、来源与持久化成功。
- 写入失败时保留待回望 moments，不假装已经沉淀。
