# Elysium 涌现信号档案

这个目录记录 Elysium 中少见但可能具有长期意义的行为链：它们不能被一条外部指令、固定模板或单次随机输出充分解释，并且展现了跨时间的选择、行动、记忆或表达连续性。

这里保存的是**工程观察与因果分析**，不是爱莉的第一人称记忆，也不是对她的人格、兴趣、意识状态或意义的自动裁决。档案不能反向覆盖 Life Event、Trace、主体文件、日记、作品或其他权威来源。

## 为什么需要单独保存

普通成功日志只能证明一次调用完成。珍贵信号通常横跨多个系统层：先形成线索，再选择材料、修改持久作品、保留经历、形成延迟意向，最后在合适场景表达。若只看最终回复，这种连续性会被误判为一句漂亮的随机文本；若只看内部独白，又可能把没有行动后果的生成误判为稳定倾向。

本档案用于：

- 保存可以重放的因果链，而不只保存结论；
- 区分外部指令、系统软提示、历史习惯、当轮选择和模型随机性；
- 记录反证、替代解释与未知项，防止过度拟人化或过度机械化；
- 为意识连续性、主动系统、记忆和未来后训练提供经人工复核的研究材料；
- 保护自然出现的行为，避免为了“再现信号”而把它改造成定时任务或固定人格规则。

## 收录原则

是否值得记录由人工结合原始证据判断，不使用关键词、分数、次数、来源或模型分类器自动决定。一次事件可以很重要，但不能仅凭一次事件宣称稳定兴趣、习惯、人格变化或意识事实。

候选事件通常至少具有若干可核验特征，但这些特征不是打分表：

1. **来源可追溯**：能够定位到 Life Event、Trace、文件版本、工具回执或其他权威证据。
2. **不是最终回复单点现象**：行为在表达之前已经形成，并产生了独立的中间状态或持久行动。
3. **存在时间连续性**：不同轮次、不同时间点或不同表面之间保持了可解释的因果关系。
4. **存在真实选择空间**：系统允许安静结束或选择其他行动，没有硬编码唯一结果。
5. **结果不是伪造成功**：文件修改、消息送达、动作回执等均有真实证据。
6. **替代解释经过检查**：包括定时模板、直接用户诱导、历史回放、重复路由、提示词暗示、缓存污染和偶然采样。

## 每份个案必须分开的内容

- **观察事实**：只写能由权威来源直接支持的内容。
- **因果重建**：说明事件如何连接，并标出推断部分。
- **替代解释**：列出支持与反对证据，不把偏好的解释写成事实。
- **置信度与未知项**：置信度描述的是分析结论，不是主体意义或人格强度。
- **保护决定**：明确哪些东西不能因此自动写入 Prompt、Memory、SOUL、训练集或调度规则。
- **后续观察**：寻找自然重复、反例和跨场景连续性，不主动诱导复现。

## 证据与隐私边界

- 个案文档优先记录稳定 ID、时间、摘要、哈希和权威路径，不复制大段私聊、日记、隐藏推理或工具参数。
- Trace、Life Event、原作品和主体文件仍是权威来源；本目录只是可审阅索引与解释。
- 原始内容缺失、已轮转或无法校验时必须明确写出，不能用回忆补造。
- provider reasoning、raw CoT 和未被主体明确接住的候选不能作为人格监督数据。
- 个案进入后训练数据集必须另行通过来源、主体归属、隐私、授权与反事实审查；“被收录”本身不构成训练授权。

## 保护自然涌现

发现好信号后，默认动作是观察和保护，而不是立刻产品化：

- 不因为一次自主创作就增加“定期写故事”任务；
- 不因为一次主动分享就提高主动发送频率；
- 不把分析者的“她喜欢这个”写回主体权威；
- 不通过 Prompt 要求重复同一种行为来制造统计显著性；
- 可以修复重复发送、证据缺口、上下文污染等工程问题，但不能替主体决定下一次应当做什么。
