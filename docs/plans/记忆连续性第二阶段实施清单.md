## 4. 统一身份和生命周期合同

- [x] 创建分配稳定 `document_id`。既有 ID 原样兼容，不因路径或内容变化重算身份。

- [x] 改名保留 document 和已有版本；新增路径事件而不改写历史 version 的旧路径。旧精确引用保持可读。

## 6. 完整历史迁移协议

现有 `copy_subject_documents_from_snapshot` 用文件快照创建首版；`export_subject_documents` 的 v1 格式输出当前版本。它们不等于全版本历史备份，也不等于 selected 数据库、authority registry、外部 blob 与其他域的完整备份。

新增完整历史 bundle 应与当前文件导出使用不同格式名／版本，且满足：

- [x] 同一数据库一致性事务枚举所有 subject documents、versions、head events、projection outbox、authority decisions、path bindings、path events、operations，不只列当前活跃路径。
- [x] 明确 schema 版本、捕获边界和每类记录 count／root；完整验证版本字节 hash／长度、记录身份、父链及引用闭包。
- [x] 保留已有 document/version/occurrence/event ID、旧路径、recorded 时间、语义 NULL、原始 bytes；不重放普通 append 生成新历史。
- [x] 导入只允许有有效写栅栏的 `CANDIDATE_COPY` runtime，并在单一事务内验证／精确插入；ACTIVE runtime、同源正式库或不明权限一律拒绝。
- [x] 同一 bundle 的相同行重放幂等；相同 ID 的不同内容或目标额外历史须拒绝且原子回退，不更新／删除既有行来凑一致。
- [x] 导入后从目标重新枚举并比较全部 count／root；不只是比较当前文件 hash。导入模块不 activate authority、不把候选标为正式可运行。
- [x] outbox 与 lease 为工程状态：精确保留仅供历史／迁移验证；恢复写入或激活前另有明确的租约／投影恢复步骤，不复用来源活跃租约。
- [x] schema 不支持、未知列／表、格式损坏、缺失记录或引用断裂必须显式失败，不静默跳过。

完整 subject bundle 只证明 subject 域。跨域 occurrence／candidate／Boundary 引用还需纳入全库迁移清单，不能仅凭此 bundle 宣称跨域备份完整。
