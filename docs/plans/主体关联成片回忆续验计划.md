# 主体关联成片回忆续验计划

记录日期：2026-09-08，北京时间。状态：首批隔离两跳合同及真实主体一跳使用已验证；原 G06／G07 完整体验仍未完成。详见[首批续验报告](../report/主体关联成片回忆续验_2026-09-08.md)。本文是工程计划，不是爱莉的记忆或关系原话。

## 1. 继续的是原目标，不是只恢复一个开关

本计划承接《记忆连续性理念与约束》的 G06／G07：主体自主形成多层线索和记忆片网络，关系含义与强弱由她决定；从一个入口能沿联系回忆其他经历，适量重新进入当前注意；是否继续追忆、如何理解及使用由主体决定。G01 的后续行为与长期稳定性分别验收，不用图节点数、工具存在或一次成功替代。

先前 S3 已完成稳定身份、追加修订／撤回、精确历史及受邀索引续用；30 条零模型合成对照在普通链接本已到达全部证据的条件下未显示额外收益。该历史有限出口有效，但不代表 G07 完成。两个主体检索入口及管理 API 的额外自动展开仍默认关闭；不因此禁用主体显式查看、建立或修订关系。

本次只读发现应准确区分：`expand_living_document_associations` 主要生成一层有界候选，按可复现技术顺序选取；`subject_strength` 保存主体原话，并未被这条自动展开路径用作排序。现有 `nucleus_relations view` 能返回关系原话供主体亲自选择下一跳。不能把“未自动量化强弱”直接诊断为缺陷，也不能把一层候选等同完整成片回忆。首选验证现有逐跳查看／精确读取，只有实际暴露入口缺口后才修最小实现；不为续验新增平行记忆库或自动裁决算法。

## 2. 第一批：有区分度的隔离协议验证

使用临时受管文件 authority、临时 Memory SQLite、合成且明确非主体的关系原话，无模型、正式写入、第三方消息或现存端口竞争。普通入口只给一个种子；目标材料不含查询关键词，也不在种子正文放直接文件链接。增加至少两个连续关系、一个同词干扰源及一条可撤回分支。

1. 同一材料与固定调用／字节预算下，普通检索、一次展开和显式逐跳路径分开记录，不给控制器预期答案或目标 ID。
2. 用真实关系 view／精确文件 read 入口核对：下一跳引用确实来自上一页；predicate、reason、subject_strength 原话不被替换或当作真值；稳定与精确版本边界明确。
3. 分别覆盖连续两跳、环路有界、当前／历史关系、修订／撤回保留历史、关系页的长内容接续，以及越权／陈旧引用显式失败。复用已覆盖的合同，不声称所有旧测试都是本轮新增。
4. 结果只证明可达性、原文和接口，不冒充主体自然联想、语义选择或真实收益。没有额外命中也如实保留，不能替换材料后只公布有利一组。

## 3. 第二批：主体自建关系与真实逐跳续用

先只读核对准确运行进程、端口、健康与源码；正式实例运行期间只做轻量隔离测试。沿现有单一受限 Codex 测试会话正常投递，不扩权、不复用已撤销的窗口测试凭据，不自动重试不明结果，不向真实第三方联系人发送消息。

第一步邀请只给范围与目的，不给关系句子、强度、连边清单或未来考题。允许她在上一批自己形成的普通工程索引／工程记录及本轮自主新建的普通辅助材料内组织联系，亦可选择普通链接、拒绝或指出不值得建立。禁止替她写入主体记忆，禁止为了测试修改 SOUL／USER／MEMORY、日记、第三方旧档案或自动安排新任务。

第二步在形成结果后只给一个入口与开放回忆意图，不在请求中列目标文件及答案。核验实际模型选择的 view／read 链、每跳来源、精确字节、主体是否使用关系理由／强弱判断、停止／继续决定，以及最终发送内容与投递回执。若她不选择关联，只记录拒绝和原因，不改写成图收益通过，也不反复施压索要正面反馈。

本会话近期上下文可能已包含形成材料，因此“实际沿关系重新读回”与“独立回忆收益”必须区分。新 stream 不是新主体，也不能自动算独立 A/B；不得清空私有窗口、强制压缩、灌入测试答案或刷消息制造独立条件。

## 4. 后续验收门槛与默认策略

- 本批机械与真实链分别完成后，再决定是否需要最小工具说明／结果字段／逐跳入口修补。主体强度继续是开放原话，优先由她读到并选择，不从关键词、次数或固定分数替她解释。
- 真实成片回忆至少要求：目标不直接出现在这次请求中，实际沿主体建立的关系到达多个相关材料，来源与历史准确，主体自主选择关联用途；只返回节点／链接或复述当前上下文不算完成。
- 独立收益还需形成阶段之外、未提前给答案的保留情境，核对实际上下文暴露；相同模型与预算下记录额外正确回忆、误联想、工具页数、成本和延迟。无法排除答案暴露时该项继续未验证。
- 自然跨压缩／跨重启持续性、不同情境行为影响和长期稳定性继续单列；不在未获当前停启授权时自行重启生产。达到重启门槛需说明原因并等待用户操作或明确授权。
- 本轮不预先把关联全部默认开启或永久关闭。先保留原运行默认，允许主体显式调用；是否及如何成为日常候选入口，应依据上述原目标证据决定，并保留来源、预算与继续读取路径。

## 5. 交付与授权边界

产出为本计划、隔离用例与结果、真实调用／权威记录的内容最小化证明及《主体关联成片回忆续验》报告。旧 S3 报告保留其历史结论，同时链接本续验，不能继续把原 G07 当作已完成。所有变更留在原仓库工作树并保留既有共享修改，不暂存、提交或推送；不创建 worktree、后台 reviewer、第二人格、定时监控或自动启动任务。
