## 范围

统一心跳机会暴露。主动系统只把 open `AttentionThread` / `InitiativeSeed` 只读投影进连续性栏；基础设施邀请进邀请栏。写入仍只走 `nucleus_proactive_query` / `nucleus_proactive_command`。学习邀请的说明书由问题 2 的 `nucleus_learn` + learning skill 承担，本总线不写 skill、不自动 `get_skill`。

## 契约

- 包：`plugins/life_engine/opportunity/`
- 字段：`offer_id / kind / domain / producer / observed_at / facts / disclosure_ref`
- `kind`：`continuity | invitation`
- 页预算：约 2–4 KiB UTF-8；先一行身份，余量展开 facts；超预算标 `omitted` + id
- 整页一个 `delivery_id`；`register_context_delivery` / exact receipt
- 冷却只针对 `kind=invitation` 且未 omitted 的 offer
- Health：due/omitted ids、kind、domain、last delivery、error_type；不含 facts 正文
