# 模型任务实际用量（2026-09-08）

只读对照 `config/models.toml`、当前插件接线，以及 Elysium / New API 日志。计数来自会写入 SQLite 的 `request=` / `routing_task=` 行（多为重试/失败/跳过）；成功且仅 debug 的轮次会偏低，但排序足够判断“谁在跑、谁是空牌”。

## 结论

真正天天在转的生成任务是 **`core`、`expression`、`learning`、`utility`**。向量任务 **`embedding`** 调用量甚至比聊天还高，只是不走 chat completions。

`live` 已从生产强制任务和 `models.toml` 删除。直播导演继续用 `actor` → `expression`。`vision` / `voice` 仍注册，但这条部署几乎没走到。`witness` / `router` / `agent` / `router_context_projection` 有代码和配置，现在要么关掉，要么几乎没人调用。

生产强制任务现为 11 个（`PRODUCTION_MODEL_TASKS` / `REQUIRED_MODEL_TASKS`）。
