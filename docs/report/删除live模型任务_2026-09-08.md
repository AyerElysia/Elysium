# 删除 `tasks.live`（2026-09-08）

操作者确认独立直播模型任务没有存在意义。现场此前已证明：直播导演 `model_task=actor` → `expression`，Elysium 日志从未出现 `routing_task=live`。

## 已执行

- 从 `PRODUCTION_MODEL_TASKS` 与 `REQUIRED_MODEL_TASKS` 去掉 `live`。
- 删除生产 `config/models.toml`、测试夹具、旧 `ModelTasksSection.live`。
- 直播导演说明改为：默认 `actor` 解析到 `expression`，不要再填 `live`。
- 同步 `docs/architecture/LLM内核.md`、`docs/architecture/直播系统.md`、`docs/operations/deployment_and_usage.md`。

未改直播插件运行时、未改 `platform == "live"` 的场景身份，未重启 Elysium。`models.toml` 只在启动时加载；要让强制任务清单在运行中的进程生效，需要用户手动重启。

## 回滚

把 `live` 加回两个 frozenset 和 `models.toml` 的 `[tasks.live]` 即可；旧候选链见删除前的本机 `models.toml` 备份习惯，Git 不跟踪该文件。
