## 2. 原因与已实现改动

| 初始缺口 | 首批实现 | 保留边界 |
| --- | --- | --- |
| `search_actor_memory` 的提示要求正文传 document_id＋version_id，但 read_file 正文拒绝 document_id | 提示改为 path＋version_id，或仅完整 file_ref；合成测试执行实际读取工具验证 | 不取消身份检查，不将基础设施的冲突指引全部归咎于调用者 |
| 多个出口已给完整 subject-file:document_id@version_id，读取工具却不接受 file_ref | 原 read_file 增加可选 file_ref，path 在该路径可省略；不新增工具或存储 | 只用于 content；不能混用 path、document_id、version_id 或历史／操作查询选择器；非法引用不转 latest |
| 两个搜索入口的关闭路径不一致；仅关闭 legacy 仍可能展开 canonical 或构建含历史关系的 bundle | 两入口 enable_association=False 跳过 canonical/living 展开和 build_memory_bundles，legacy 与 evidence-aware 调用也关闭额外关联 | 默认 True 不变，直接检索证据仍可返回；不是纯文件搜索或全部证据关闭，不宣称新增图增强已有收益 |

精确读取复用原授权 session：先获取 selected descriptor 与 document head，检查 document/version 对应、工作区 namespace、规范历史路径及 symlink alias；随后进入原 `session.read` 读取权威 bytes 并校验 hash；返回前再核对 snapshot 的 document、version 和完整 ref。引用不授予额外权限，未启用 selected storage 时明确拒绝。

历史引用固定原 document/version，更新、改名、删除、地址复用和存储重开不将其绑定到当前路径占用者。旧 path＋version_id 保持兼容；file_ref 续读必须保留原引用和读取参数，continuation 继续校验固定版本、范围与预算。文本解码和行号是显示投影，不保留 CRLF 原样的承诺；文件 hash 对应保存的原始字节。

本批没有新增 relation/schema、迁移旧关系、写主体线索或修改主观内容。Boundary 既有 exact_uri 读取路径未改动；S3.2 的稳定关系端点、修订／撤回和可选主体强度，以及 S3.3 的收益对照均未实施，不能由关闭路径通过推导为完成。
