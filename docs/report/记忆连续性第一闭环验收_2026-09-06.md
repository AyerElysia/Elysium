## 4. 明确未完成的部分

1. **真实启动及自主体验未验收。** 必须由用户手动启动，再进行两次自主压缩、一次手动重启及未提前告知的近期回忆测试。没有调用真实模型证明其学习/技能/承诺效果。
2. **全部文件空间尚未统一。** 本轮代表路径是 MEMORY，固定 SOUL/USER共享保护；稳定文件ID、改名、删除、所有写入口和二进制版本化仍在 S2。
3. **部分提交回执仍需收敛。** 权威版本已提交、local projector因陈旧/缺失磁盘拒绝覆盖时，工具仍可能整体报失败。本轮保留此安全保护，测试证明新版本与旧历史不丢、磁盘不被强写；使用者需要重新读取权威确认状态。尚未统一成明确的“已提交、投影待处理”结构化回执。
4. **没有 pending 决定自动恢复数据库。** 结果快照提交前崩溃恢复旧快照，由当前主体重新决定压缩；不是自动重放已遗失的 process-local pending。缺失可信快照时从整条历史自动重建窗口也未实现。
5. **没有完善外部传输 exactly-once。** 上游平台重试/outbox仍是独立边界，原始账本幂等不等于任何外部发送都只发生一次。
6. **没有全格式、多机器与真实 MySQL 故障验收。** 两个心跳读者的CAS契约已测试，但不能据此替代分布式权限、租约、断网恢复和实际部署验收。

计划 S1 的广义所有出口尚不能全部打勾：正常工程最小链已成立，部分提交体验与真实运行验收仍待后续。后面的关联、时效、技能验证及承诺对照不得以本次测试数量冒充完成。
