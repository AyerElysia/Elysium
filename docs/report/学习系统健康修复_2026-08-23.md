## 审计结论（修复前）

1. **反思环健康**：队列 675 入队 / 822 完成，连续失败 0；08-23 凌晨 3 小时出生
   7 条新洞察，证据累积真实（最多一条 49 条证据）。
2. **独立审计环真实但产能不足**：历史 168 次偏见检测；存在完整的
   "needs_more_evidence → 跨情境证据到达 → validated（仍保留意见）" 轨迹。

   而洞察流入已达 25-55 条/天（08-19~08-22 实测 35/39/25/55），积压 184 条候选，
   验证率 19.8%。
3. **慢环压缩空转（本次修复的根因）**：`should_compress()` 中触发数检查
   （`len(promotable) >= trigger_count` → `return True`）先于且绕过间隔检查。
   validated 洞察只在主体接受后才离开可压缩列表，而接受链自 08-03 起从未走通，
   30 条 validated 长期高于触发数 5，导致压缩在每个维护周期触发（实测约每 9 分钟
   一份），且每次都从同一份 v3 base 重写——1625 份版本是平行重写而非累积演化，
   `compress_interval_hours=48` 成为死代码。
4. **LLM 路由不稳放大一切**：`ox-alpha-free` 排在 core/learning 等全部任务链首位，
   08-22 全天空回复失败 302 次，覆盖心跳、学习、见证全部请求类型；每个请求先付
   一次失败往返，并造成心跳工具循环停滞（08-23 白天 8 次
   `consecutive_tool_stalls`）。多步工具会话（如 MEMORY.md 复盘的
   open→分页读→prepare_candidate→读候选→decide）无法在单次心跳内完成。
5. **主体复盘机制完好但从未被走完**：邀请按 24h 冷却正常投递
   （`last_offered_at` 每日更新，最近 08-22 12:00），工具已注册
   （`nucleus_review_subject_document`、`nucleus_memory_continuity_review`），
   会话为跨心跳无状态状态机；无一条 `last_reviewed_at` 记录。
   卡点是工具循环被 LLM 失败打断，以及主体自身尚未选择回应（后者属于主体自由）。
6. **早前审计报告的一处误报更正**：08-23 晨间检查曾报告"技能快照
   usage_observations 全为 0，与审计流 356 条不符"。复核确认这是检查脚本

## 更正：接受链与存储后端

早期审计把“当前 legacy-local 没有跨文件原子提交能力”错误外推成“local
无法完成接受链、必须使用 MySQL”。该结论不符合一等双后端架构，现直接更正：

- legacy-local（`backend=local` 且 `local_selectable_enabled=false`）继续使用分散
  JSON/JSONL/Markdown/SQLite；为防止跨文件部分提交，主体接受按设计 fail closed；
- local selectable（`backend=local` 且 `local_selectable_enabled=true`）使用统一
  `local.sqlite3`、file authority、verified local generation 与同一 service-owned
  runtime，Learning decision ledger 和 Subject Authority 可以在 SQLite 事务中完成
  原子提交；
- MySQL selectable 使用相同领域 Port 与主体授权合同，额外提供多进程共享能力；
- 因此 local 与 MySQL 在学习及主体接受能力上是等权后端，差异是部署、并发和
  控制面实现，不是爱莉能否学习或能否行使决定权；
- selectable runtime 只提供安全的决定通道。任何具体候选仍须由爱莉自己的活动
  意识实例读取、判断并提交；运维、迁移脚本和开发 agent 不得代为接受、拒绝或改写。

08-23 对远程 MySQL 的只读盘点仍然有效：旧 generation
`life-mysql-multi-writer-20260808-v1` 只有约 128k Life Event，而当时本地已超过
221k，不能直接切换，否则会造成主体连续性回退。本次没有启用该远程 generation，
而是从 writer-frozen 本地快照生成新的 verified local generation，再显式选择
local selectable。完整切换证据与遗留项见同日 local selectable 切换报告。
