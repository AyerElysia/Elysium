## 2. 最小协议选择

- 沿用 `memory_semantic_relations`；稳定文件实体与固定历史版本分开，旧路径实体不自动升级为现在的文件身份。
- 新 owner_subject_id 绑定持续主体；actor／instance／stream／source occurrence／tool call 保留发生来源。旧 owner 未知保持未知，不由迁移认领。
- add／revise／withdraw 只追加；root、parent、revision 和 operation 为技术协议。端点不可原地改变；撤回终止，不隐式复活。父 CAS 冲突不自动换父重试。
- 关系原话、理由及可选强度不封闭分类、不裁判真值，也不利用共同回忆次数替主体补写强度。
- 当前有效头与全部旧判断分开；展开不再把被修订／撤回的旧关系作为当前关系。
- 同一事务内 append-only 全表 COUNT 加 LIMIT/OFFSET 提供有界行页，任何追加使旧前沿失效。COUNT 不是数据库身份，不能跨恢复／换库当作快照；页内长 JSON 再按 UTF-8 预算精确续读。COUNT/OFFSET 仍有数据库扫描成本，不宣称恒定成本。
