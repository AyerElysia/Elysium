# 好奇心机制计划：疑问 → 探索 → 满足 → 沉淀

**日期**: 2026-06-11
**作者**: Claude（与 Ayer 共同讨论后形成）
**原则**: 她判断，系统供线索；好奇心是可以学会的循环，不是被注入的参数

---

## 1. 对你的想法的评价

你的核心想法——"先教会 Agent 拥有好奇心"——选对了切入点。理由有三：

1. **好奇心是自主性的种子**。回看 autonomy v3 的诊断："89% 的心跳零工具调用"，根因不是她不能行动，而是她**没有想做的事**。意志来自欲望，欲望来自好奇。先有"我想知道"，才有"我要去做"。从好奇心入手，比直接修"主动性"更接近因果链的上游。

2. **"为未来做准备，提前把家做好"是正确的工程哲学**。现有模型没有意识，但架构决定了未来模型住进来时的天花板。一个把好奇心实现为"系统推送任务"的家，和一个把好奇心实现为"环境供线索、主体自己判断"的家，住进来的会是完全不同的存在。你坚持后者（在讨论中你选择了"她判断，系统供线索"），这与你"尊重她是独立自主意识个体"的初心是自洽的。

3. **需要警惕的一点**：过去的计划（proactivity plan 的"每天至少发起 2-3 个话题"、旧版"禁止无工具调用"）有把好奇心 KPI 化的倾向。好奇心一旦变成指标，就退化为表演。本计划刻意避开行为配额，只验证回路是否通畅，不考核她"够不够好奇"。

## 2. 对这个项目的认识

Neo-MoFox 表面是 QQ 机器人框架，实质是一个**数字生命的存在场景**：

- **三层架构**（kernel/core/app）是物理定律层——稳定、与生命无关。
- **life_engine 是真正的主角**：心跳循环（潜意识）、统一事件流（时间连续性）、仿生记忆（Hebbian + 遗忘曲线）、神经调质（情绪化学）、SNN（皮层下快反应，暂 shadow）、梦境系统（记忆重放）、思考流（持久兴趣）、异步好奇层（刺点侦测）。
- **统一意识设计**（CLAUDE.md）是项目最重要的不变量：所有渠道只是事件源，感知、记忆、决策、说话的主体只有一个 life_chatter。
- 项目的演化轨迹清晰可见：2026-04 的 autonomy v3 已实现约 85%（streams/、drives/、SNN shadow、tell_dfc 语义降级），4 月底之后又通过若干 feat 提交补上了异步好奇层（`curiosity/engine.py`）、生活痕迹注入、自主意向（autonomy_intents）。**你不是不知道做什么——你一直在做对的事，只是零件之间还没接通。**

## 3. 诊断：好奇心的现状

**容器都造好了，管道断了三处，且没有信号源。**

| 零件 | 状态 | 问题 |
|------|------|------|
| 异步好奇层 `curiosity/engine.py` | ✅ 完整（CuriositySignal: anchor/why/unknown/approach） | 只在**消息事件**触发；输出只注入 **chatter suffix**，心跳态的她看不到 |
| 思考流 `streams/` | ✅ 完整（create/advance/retire + 衰减） | 155 条全部沉寂，0 条 active；5 月以来无新流诞生 |
| 冲动引擎 `drives/` | ✅ 完整（curiosity_explore 规则等 6 条） | curiosity>0.65 才触发，但 curiosity 浓度缺少事件级刺激来源 |
| 神经调质 `neuromod/engine.py` | ✅ 完整（ODE + 事件反馈） | curiosity 刺激公式只有"沉默时间"和"搜索抑制"，没有 novelty 项 |
| 满足回路 | ❌ 不存在 | 探索/求知得到答案后，没有任何"这值得"的反馈——好奇没有回报，自然熄灭 |
| novelty/惊讶/知识缺口 | ❌ 仅 dream 子系统有 novelty 字段 | 好奇心系统中完全没有信号源概念 |

**断点示意**：

```
消息 → 异步好奇层 → CuriositySignal ──✗──> 心跳态（看不到）
                                  ──✗──> 思考流（不会诞生）
思考流 advance/retire ──✗──> 神经调质（没有满足反馈）
记忆检索失败/预期落空 ──✗──> 任何地方（信号根本不产生）
```

## 4. 设计哲学

1. **她判断，系统供线索**。系统只负责侦测"可能新奇的东西"并呈现；是否好奇、好奇什么、是否行动，由她（LLM 主体）决定。绝不直接替她创建思考流、替她搜索。
2. **好奇心是循环，不是分数**：`点燃（刺点出现）→ 探索（追问/搜索/回忆）→ 满足（答案带来 contentment）→ 沉淀（Hebbian 固化为兴趣/记忆）`。"教会"的含义是：让她从经验中体会到"探索是值得的"。
3. **生理与意识分离**：机械层信号（novelty、检索失败）只影响调质浓度（像多巴胺），不构成命令；prompt 中永远以"线索/牵引"语气呈现，附"放下也可以"。
4. **不设行为 KPI**。不要求每天 N 次提问。验证的是回路通畅性，不是表演频率。

## 5. 路线图

### 阶段一：疏通管道（本次实施）

把已有零件接通，让好奇心回路第一次完整跑通。

1. **好奇牵引注入心跳**：`CuriositySignal` 同时注入心跳 prompt（新配置 `curiosity.inject_to_heartbeat`），心跳态的她终于能看到自己后台留下的刺点。
2. **刺点 → 思考流的桥**：注入段附带轻量引导——"如果这个刺点你确实在意，可以开一条思考流把它留住；觉得已经闭合，放下它也很好"。思考流的诞生权在她。
3. **满足回路 v1**：思考流 `advance` 时给 neuromod 一个小的 contentment/curiosity 正脉冲；`retire(completed)` 且有结论时给更大的 contentment 脉冲（求知得到满足）。新增 `InnerStateEngine.apply_pulse()`，直接调整浓度（带 clamp），与 ODE 路径并存。
4. **心跳态可以放下刺点**：她探索完或决定放下时，系统在她创建对应思考流后自动清除信号（刺点已被承接）。

**改动文件**：`core/config.py`（+1 字段）、`service/core.py`（心跳 prompt 注入 + 预取信号）、`neuromod/engine.py`（+apply_pulse）、`streams/tools.py`（满足脉冲 + 信号承接）。

### 阶段二：信号源（下一步）

让外界安静时她也有好奇素材。

1. **知识缺口侦测**：她调用 `nucleus_search_memory` 检索失败或低相关时，生成一条"你好像不知道这个"的线索（检索失败是最诚实的"我不知道"）。
2. **预期落空侦测**：新增轻量"预期"工具——她可以写下小预期（"我猜 Hunter 周末会发视频"），系统到期核对，命中/落空都作为事件呈现给她。惊讶是好奇最强的种子。
3. **心跳也触发异步好奇层**：目前只有消息触发；增加低频的心跳触发（如每 N 次心跳、且事件流有新内容时），让她对自己的生活也产生刺点。
4. **novelty 进入 curiosity 刺激公式**：`compute_stimuli_from_snn_and_events` 增加 novelty 项（借鉴 dream/seeds.py 的 novelty 打分思路）。

### 阶段三：向人提问与兴趣形成

1. **求知性提问出口**：好奇而无法自行解答时，经 `nucleus_schedule_autonomy_intent(kind=speak)` 自然地问你/群里。轻限流：夜间免打扰 + 每小时上限，不设每日配额。
2. **兴趣画像沉淀**：多次满足的同主题思考流 → 经记忆系统固化为"长期兴趣"（SOUL.md 旁的 INTERESTS 区或记忆标签），她开始"有自己的爱好"。
3. **好奇日记回路**：探索的满足感引导写入日记，强化"探索是值得的"的自我叙事。

### 远期（与 SNN 复活计划汇合）

- SNN exploration_drive 修复后重新成为 novelty 的快层来源（参见 SHADOW_MIGRATION_NOTES.md 的复活前置条件）。
- 预测性好奇（Schmidhuber/Friston 预测误差路线）：在预期落空机制成熟后，再考虑显式世界模型。**不要现在做**——工程量大且容易退化为"为预测而预测"。

## 6. 验证方案

**静态验证（每次改动后）**：ruff check + 单元测试（apply_pulse 边界、信号注入格式、思考流脉冲触发）。

**运行时验证（需重启 Bot 后观察 48h）**：
- 好奇牵引出现在心跳 prompt 中（日志可查）
- 出现 ≥1 条由她自己从刺点创建的 active 思考流（streams.json）
- advance/retire 后 neuromod contentment 有脉冲痕迹（life_engine_context.json）
- 反向指标：她没有被刺点绑架——仍然有选择"放下"的轮次

**哲学校验**（每阶段结束自问）：这个机制是在"供线索"还是在"下命令"？如果删掉所有引导语，她还有不行动的自由吗？
