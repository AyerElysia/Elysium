## 0. 一句话定位

爱莉小画室是**高质量图片生成**插件：对接 NovelAI 官方 API，支持 Vibe 参考图、多密钥轮换、类级别任务队列防 429，通过 LLM Action 接受自然语言画图委托。

## 2. Action 层

### 2.1 DrawAction — 通用画图委托

- **触发条件**：用户明确提出画图、生成图片、做素材/壁纸/头像/插画/设定图/配图
- **职责边界**：不生成聊天表情包/贴纸/反应图（那些走 emoji 插件）
- **提示词规范**：
  - 使用生动的英文自然语言描述
  - 涵盖主体、环境、光影、构图、艺术氛围
  - 像给人类画师下委托一样写清楚
- **画幅选择**：支持任意自定义尺寸（16:9 宽屏、方图、肖像竖图等）

### 2.2 SelfieAction — 自拍/生活照

- 角色一致性（固定角色特征描述）
- 生活场景化（日常、旅行、节日等）
- 与 DrawAction 共享底层服务

### 2.3 BaseImageAction — 公共基类

- 统一的图片发送逻辑
- 错误处理与用户提示
- 生成参数校验

## 3. 核心服务（ImageGeneratorService）

### 3.1 任务队列机制

```python
# 类级别队列 — 所有实例共享，串行化请求
_task_queue: asyncio.Queue
_queue_worker_started: bool
_queue_lock: asyncio.Lock
```

所有生图请求进入全局队列，单 worker 串行消费，确保不触发 NovelAI 的 429 限流。

### 3.2 多密钥轮换

- `openai_api_keys[]` — OpenAI 兼容引擎密钥池
- `novelai_api_keys[]` — NovelAI 官方密钥池
- 独立 index 轮换，请求间 cooldown（默认 20s）

### 3.3 Vibe 参考图系统

| 类型 | 说明 |
|------|------|
| 预设 Vibe | 启动时编码好的风格参考图 |
| 用户 Vibe | 用户上传的参考图（按 user_id 索引） |
| 可选 Vibe 池 | 按名称索引，支持自动选择 |
| 手动 Vibe | 用户指定使用某张参考图 |

### 3.4 生成参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| steps | 28 | 采样步数 |
| scale | 5.0 | CFG 引导强度 |
| resolution | 配置 | 输出分辨率 |
| noise_schedule | 配置 | 噪声调度 |
| model | 配置 | 模型选择 |
