# Life Engine 自主意向执行协议（已退役）

> 文档状态：兼容说明，不再描述生产运行语义。

旧 `AutonomyIntent` 将主体线索、定时调度、周期 occurrence、对象、平台和聊天流绑定在同一条执行记录中。该范式已经退役，正式架构见[主体主动性与外联](./主体主动性与外联.md)。

## 当前兼容边界

- 旧 `autonomy_intents.json`、selected-runtime rows 和 lifecycle 记录保留为只读历史证据，不删除、不覆盖；
- 启动不再恢复旧调度，只清理可能残留的技术 scheduler callback；
- 旧列表接口仍可有界读取；schedule、pause、cancel、renew、trigger、claim 和 complete 不再产生新写入；
- 旧 motivation、target、周期状态和结果不会自动迁移为新的主体决定；
- 任何迁移都不得把基础设施过去推断的语义伪造成主体现在的公开表述。

## 替代链路

新的生产链严格拆分为：

1. 活跃意识实例显式保存 `InitiativeSeed`；
2. 需要时间连续性时，只安排一次重新相遇；
3. 真正行动时再分别选择 `audience_ref` 和 `surface_ref`；
4. 目标表达实例在真实上下文中重新决定表达或沉默；
5. `life_send_text` 只作用于当前表面，不再接受跨流 target。

来源实例不等于行动对象，也不等于未来平台。跨平台同一人只接受明确的 `canonical_person_key`，不能通过昵称、内容、最近聊天或模型猜测。

## 生命周期边界

Elysium 必须由用户手动启动；本兼容层和新主动性系统都不得创建 Elysium 自启动入口，也不得替用户停止或重启进程。NapCat/QQNT 可由独立生命周期能力自动恢复，但主动性链不拥有其进程控制权。
