## 0. 一句话定位

TTS Voice 是**本地语音合成**插件：基于 GPT-SoVITS / Higgs 引擎，支持多风格语音合成、情绪/韵律控制标签、空间音效后处理，通过 LLM Action 或关键词触发。

## 2. Higgs 控制标签系统

Higgs 引擎支持在文本中嵌入控制标签，引擎解析为情绪/韵律/风格/拟声音效：

### 2.1 情绪标签（emotion）

| 标签 | 效果 |
|------|------|
| `<\|emotion:elation\|>` | 愉悦狂喜 |
| `<\|emotion:enthusiasm\|>` | 兴奋高昂 |
| `<\|emotion:contentment\|>` | 平静满足 |
| `<\|emotion:affection\|>` | 亲昵爱意、想念、撒娇 |
| `<\|emotion:relief\|>` | 释然松气 |
| `<\|emotion:contemplation\|>` | 思索回忆 |
| `<\|emotion:sadness\|>` | 难过失落 |
| `<\|emotion:fear\|>` | 害怕紧张 |

### 2.2 风格标签（style）

| 标签 | 场景 |
|------|------|
| `<\|style:whispering\|>` | 耳语轻声：道别、睡前呢喃、贴耳撒娇 |
| `<\|style:shouting\|>` | 喊话：远距离呼唤、欢呼 |
| `<\|style:singing\|>` | 唱腔：哼歌、撒娇拖腔 |

### 2.3 拟声音效（sfx）

| 标签 | 效果 |
|------|------|
| `<\|sfx:laughter\|>` | 笑出声 |
| `<\|sfx:cough\|>` | 咳嗽 |
| `<\|sfx:sigh\|>` | 叹气 |
| `<\|sfx:sneeze\|>` | 打喷嚏 |
| `<\|sfx:crying\|>` | 哭泣 |

### 2.4 韵律标签（prosody）

| 标签 | 效果 |
|------|------|
| `<\|prosody:speed_fast\|>` | ~1.2x 加速 |
| `<\|prosody:speed_slow\|>` | ~0.8x 减速 |

标签可叠加使用，写在句首，由 LLM 按表达需要自由组合。

## 3. 核心服务（TTSService）

### 3.1 风格管理

- 多套 TTS 风格配置（参考音色 + 参数）
- 从配置文件加载 `tts_styles` 字典
- 支持运行时切换风格

### 3.2 文本清洗

- 去除 Markdown 标记
- 长度截断（默认 500 字符）
- 特殊字符转义

### 3.3 空间音效后处理

使用 `pedalboard` 库：
- `Reverb` — 混响（模拟空间感）
- `Convolution` — 卷积（IR 脉冲响应）
- 可配置的空间效果参数

### 3.4 引擎后端

- 默认对接 GPT-SoVITS API 协议
- 支持 Higgs 引擎（带控制标签解析）
- 后端可替换（抽象接口）

## 4. 触发方式

| 方式 | 说明 |
|------|------|
| LLM Action | 主意识决定发语音时自动调用 |
| 斜杠命令 | `/tts <文本>` 直接触发 |
| 关键词 | 配置中定义的触发词 |

## 5. 配置节一览

| 配置节 | 说明 |
|--------|------|
| `plugin` | 启用/自启 |
| `components` | 依赖组件声明 |
| `prompt` | 提示词（引导 LLM 何时使用语音） |
| `tts` | 核心参数（端点、超时、最大长度、默认风格） |
| `styles` | 多套风格定义（参考音色、语速、音调） |
| `advanced` | 高级参数（采样率、编码格式） |
| `spatial_effects` | 空间音效（混响/卷积参数） |
