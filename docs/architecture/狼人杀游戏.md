## 0. 一句话定位

Werewolf Game 是一个**商业级 QQ 群狼人杀引擎**：完整实现警长竞选、守卫/猎人/白痴、遗言系统、平票 PK、狼人自爆、板子配置、AI 玩家策略决策和戏剧化叙事，规则判定完全由确定性代码实现（无 LLM），LLM 仅用于 AI 玩家的白天发言生成。

## 2. 角色系统

| 角色 | 阵营 | 技能 |
|------|------|------|
| 狼人 | 狼 | 夜晚击杀，白天可自爆 |
| 预言家 | 神 | 每晚查验一人身份 |
| 女巫 | 神 | 解药/毒药各一瓶 |
| 猎人 | 神 | 被狼刀/投票出局时开枪（被毒不能开枪） |
| 守卫 | 神 | 每晚守护一人（不能守自己，不能连续守同一人） |
| 白痴 | 民 | 被投票出局时翻牌免疫，之后不可投票 |
| 村民 | 民 | 无特殊能力 |

## 3. 阶段状态机

```
WAITING → NIGHT → DAY_BREAK → SHERIFF_ELECTION(仅第一天)
    → SPEAKING → VOTE → PK_VOTE(平票时) → LAST_WORDS
    → HUNTER_SHOT(触发时) → NIGHT → ...
    → ENDED
```

### 夜晚结算顺序

1. 守卫选择守护
2. 狼人选择击杀
3. 女巫决定是否用药
4. 预言家查验
5. 统一结算（守卫挡狼刀 > 女巫救人 > 狼刀生效；毒独立生效）

---

## 4. 核心机制

### 4.1 警长系统

- 第一天白天进入竞选：报名 → 投票 → 当选
- 警长权力：投票 1.5 票、决定发言顺序
- 警长死亡：移交警徽或撕毁

### 4.2 遗言规则

- 第一晚死者有遗言
- 第二晚起：单死有遗言，多死无遗言
- 白天被投票者有遗言
- 狼人自爆可留遗言

### 4.3 平票 PK

- 投票平票 → 平票者上 PK 台
- PK 台玩家再发言 → 其余玩家再投票（PK 者不能投）
- 再次平票 → 无人出局（平安日）

### 4.4 胜负判定

- **屠城制**：狼人 >= 好人即狼胜
- **屠边制**：杀光村民 OR 杀光神职即狼胜

## 5. AI 玩家

| 决策类型 | 实现方式 | 说明 |
|----------|----------|------|
| 夜晚行动 | 规则引擎 | 快速、确定性、按角色优先级 |
| 投票 | 规则引擎 | 带随机性 + 难度加成 |
| 白天发言 | LLM 生成 | 信息隔离 + 角色伪装 |
| 猎人开枪 | 规则引擎 | hard 模式偏向实际狼人 |
| 狼人自爆 | 规则引擎 | 仅最后一狼时低概率触发 |
